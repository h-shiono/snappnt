# 有線試験の手順（M3）

発生器からXIAO ESP32C3へ、ケーブルとアッテネータで直接信号を入れる試験です。**電波を空間に出さない**ことが前提です。

## 安全と法令

- 発生器（HackRF、B210クローン）には**アンテナを付けない**。ケーブルとアッテネータで閉じた経路だけで行う。
- 2483.5–2500 MHzは衛星系（Globalstarなど）と共用の帯域。アンテナから送信すると無線局の免許が必要になり、他の受信機への妨害にもなる。
- 漏れを減らすため、可能なら受信機側を金属ケースに入れる。
- HackRFは必ずアンプOFF（`-a 0`）、アンテナポート給電OFF（`-p 0`）。`snappnt.io.generators.hackrf_transfer_cmd` はこの2つを常に付ける。
- **アッテネータなしで発生器とESP32を直結しない。** ESP32の入力を傷める恐れがある。
- snappnt は送信を自動で行わない。コマンドは人が確認して実行する。
- 法令の厳密な線引きは各自で確認すること。

## 接続

```
B210クローン（送信）─ 30 dB ─ 分配器 ─┬─ 30 dB ─ DCブロック ─ XIAO ESP32C3（u.FL）
                                      └─ 30 dB ─ B206mini-i（基準受信機）
```

- XIAO ESP32C3のu.FLは、RFスイッチを介さずにLNA入力へつながっている。
- 分配器でB206mini-iにも同じ信号を入れる。基準受信機で捕捉できてESP32で捕捉できなければ、原因はESP32側（取り込み・利得・周波数）にあると切り分けられる。
- アッテネータの値は目安。まず合計60〜70 dBから始める。

## 手順

1. **再生用ファイルを作る。**
   `snappnt sim scenarios/navic_s_conducted_gen.yaml --uhd --hackrf`
   - 長さは1秒（NavICのデータシンボル50個分）なので、繰り返し再生しても継ぎ目でシンボルが途切れない。
   - 搬送波は発生器の中心から +1.5 MHz ずらしてある。発生器の局部発振器の漏れ（中心に出る直流成分）が信号に重ならないようにするため。
   - 雑音はソフト側で加えてあるので、C/N0はシナリオの値で決まる。ESP32へは−60〜−70 dBm程度の扱いやすい強さで入れればよい。
2. **発生器の中心周波数を決める。**
   中心 = 2492.028 MHz − 1.5 MHz = 2490.528 MHz。SigMFメタデータの `core:frequency` にも同じ値が入っている。
3. **送信する（人が手動で）。**
   `snappnt.io.generators.uhd_tx_cmd(...)` または `hackrf_transfer_cmd(...)` でコマンドを組み立て、内容を確認してから実行する。
4. **XIAOで取り込む。**
   `io/espsdr_client.py` を完成させる（TODO: チューニングと取り込みのコマンド書式）。取り込んだデータはSigMFに保存する。
5. **捕捉する。**
   `snappnt acquire <file> --signal navic_s_sps --prn 10 --freq-span 60000`
   ESP32と発生器の水晶のずれを合わせると数十kHzになり得るので、探索範囲は広めに取る。
6. **C/N0を振って比べる。**
   シナリオのC/N0を変えて再生用ファイルを作り直し、捕捉確率を測る。`snappnt sweep scenarios/navic_s_esp32c3.yaml` で出したシミュレーションの曲線と重ねる。

## 次の段階：信号だけを弱く入れる

雑音を加えずに信号だけを−130 dBm前後まで減衰させて入れると、ESP32自身の雑音指数や、低いサンプルレートでの折り返し損失を含めた実際の感度が分かる。このレベルでは発生器からの漏れが効くので、アッテネータを多段にし、シールドを確実にする。
