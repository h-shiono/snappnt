# 決定記録

設計上の判断を、新しいものを下に追記していきます。各項目には「何を決めたか」「なぜか」「他の選択肢」を書きます。

## D-001 シミュレータと受信処理を同じリポジトリに置く（2026-09-30）

- **決定：** ホスト側（シミュレータ、受信処理、評価）は1つのリポジトリ `snappnt` にまとめる。ESP32のファームウェアは、改造が必要になった時点でESP-SDRをフォークした別リポジトリにする。
- **理由：** 信号の定義（拡散符号、搬送波、チップレート）を両者で共有する。「生成→捕捉→正解と照合」の試験を1か所でCIに載せられる。当面は1人で両方を同時に直す。
- **他の選択肢：** シミュレータを `snappnt-sim` として分離する。シミュレータ単体を他人に配る必要が出たとき、または信号定義が安定して独立ライブラリにできるときに再検討する。

## D-002 ライセンスは BSD-2-Clause（2026-09-30）

- **決定：** BSD-2-Clause。
- **理由：** 普及を優先する。RTKLIB/MRTKLIBと同じなので、コードを行き来させるときに迷わない。収益化はライセンスではなく、サービス・受託・ハードウェアで行う。
- **他の選択肢：** Apache-2.0（貢献者からの特許許諾が明示される）。企業からの貢献が現実的になったら再検討する。当面は CONTRIBUTING.md のDCO（コミットごとの署名）で最低限の手当てをする。

## D-003 本体はPythonで書き、MATLABには依存しない（2026-09-30）

- **決定：** numpy / scipy / pyyaml のみに依存する。MATLABの波形生成は、相互チェック用の任意の道具にとどめる。
- **理由：** Toolboxのライセンスがなくても誰でも動かせるようにする。

## D-004 SigMFの読み書きは自前の最小実装（2026-09-30）

- **決定：** `io/sigmf_io.py` に最小限の読み書きを実装し、`sigmf` パッケージには依存しない。
- **理由：** 必要な機能（cf32/ci16/ci8の読み書き、正解の注釈）が小さい。依存を増やさず、ライセンスの確認対象も増やさない。
- **他の選択肢：** 公式の `sigmf` パッケージ。検証機能が必要になったら導入を検討する。

## D-005 拡散符号はICDの印刷値と照合する（2026-09-30）

- **決定：** 符号生成器には、ICDに印刷された値（先頭10チップの8進表記など）を試験ファイルに書き写して照合する試験を必ず付ける。
- **理由：** 生成器の出力から期待値を作ると、誤りも一緒に「正解」になってしまう。
- **実績：** NavIC L5/S SPS の全28本が IRNSS SIS ICD for SPS v1.1 の Table 7 と一致。G2初期値の表は PocketSDR（BSD-2-Clause）の表とも一致することを確認済み。GPS L1 C/A の PRN 1〜10 も IS-GPS-200 と一致。

## D-006 README は英語、docs と CLAUDE.md は日本語（2026-09-30）

- **決定：** 公開を前提に README.md は英語。設計資料と作業指示は日本語で書き、理解の負担を減らす。
- **他の選択肢：** docs も英語にする。外部の貢献者が増えたら再検討する。
