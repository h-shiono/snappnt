# 設計

## 全体の流れ

```
                 ┌──────────── signals（どの信号か） ────────────┐
                 │ catalog/*.yaml ＋ codes/（拡散符号の生成器）   │
                 └───────────────┬───────────────────────────────┘
                                 │
   scenarios/*.yaml ──▶ sim ──▶ SigMF（信号＋正解の注釈）──▶ rx（捕捉）──▶ eval（正解と照合）
                         │                                    ▲
                         └─▶ 再生用ファイル（int8 / sc16）      │
                               │                               │
                               ▼（人が手動で送信、有線のみ）      │
                          発生器 ─▶ アッテネータ ─▶ ESP32 ──▶ SigMF（正解なし）
                                                   frontend（機材の制約と周波数配置）
```

受信処理（rx）は、SigMFファイルが「シミュレータ製」か「ESP32で取り込んだもの」かを区別しません。どちらも同じ形式で受け取ります。シミュレータ製のファイルには正解の注釈が付いているので、eval で自動照合できます。

## 3つの層を分ける理由

NavIC以外の信号やC帯に広げるとき、変更が1か所で済むようにするためです。

1. **信号の定義（signals）**
   搬送波周波数、チップレート、符号長、変調方式、データのシンボルレート、パイロットの有無をYAMLに書きます。拡散符号は `code_family` の名前で生成器を引きます。
   新しい信号の追加は「YAMLを1つ」「生成器を1つ」「ICD照合試験を1つ」で完結します（`.claude/commands/add-signal.md`）。

2. **フロントエンドと周波数配置（frontend）**
   機材ごとの制約（サンプルレート、ADCのビット数、1回の最大取り込みサンプル数）と、外部ミキサを含む周波数の変換を扱います。
   ミキサの局部発振器（LO）を信号より高い側に置くと、中間周波数でスペクトルが左右反転し、ドップラーの符号が逆になります。これを `FrequencyPlan.doppler_sign` で表しています。

3. **データ形式（io）**
   IQ記録にはSigMF（生データ＋JSONのメタデータ）を使います。シミュレータの正解は、`core:label` が `truth` の注釈に `snappnt:truth` として入れます。

## 捕捉アルゴリズムの要点（rx/acquisition.py）

- ESP32は80 MSa/sで約0.2 msしか取り込めず、NavICの符号1周期（1 ms）より短くなります。そのため、「取り込んだ断片」と「符号1周期＋断片長の長さの参照信号」を相関させ、断片が符号のどの位置から始まったかを全位相で探します。
- 周波数方向は、搬送波をずらしながら同じ相関を繰り返します。探索の刻みは既定で 1/(2 × 積分時間) です。
- `n_blocks` を2以上にすると、取り込みを区間に分けて別々に相関をとり、電力で足し合わせます（非コヒーレント加算）。データビットの反転や周波数の刻み誤差に強くなる代わりに、感度が少し落ちます。
- 検出のしきい値は、雑音だけのときに探索範囲全体で誤検出が起きる確率が `pfa` になるように決めます。
- C/N0の推定値は、各種損失を無視した簡易値です（実際より低めに出ます）。

## 用語

| 用語 | 意味 |
|---|---|
| 取り込み（スナップショット） | ESP32などが一度にメモリへ書き込むIQサンプルの塊。連続受信ではない |
| コード位相 | 取り込みの先頭サンプルが、拡散符号のどのチップ位置にあたるか（単位：チップ） |
| 周波数ずれ | 周波数配置で決まる中心から、実際の搬送波がどれだけずれているか。ドップラーと受信機の水晶の誤差の合計 |
| 正解（truth） | シミュレータが信号を作るときに使った値。捕捉結果と比べるために記録する |
| 有線試験 | 発生器と受信機をケーブルとアッテネータで直結し、電波を空間に出さずに行う試験 |
